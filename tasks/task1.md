
​Create a landing page for the CAC Poverty Simulation following the approved Figma design.​ The landing page serves as the primary entry point to the application and has 3 main actions:​ ​Play the Simulation, Learn About CAC, and Donate.​

# ​Implementation Requirements​

1.​ ​Implement Landing Page Layout​
​   ●​ ​Create the landing page based on the approved Figma prototype.​
​   ●​ ​Include CAC branding, introductory text, and relevant visual elements as​ provided by the repository - pause implementation if a particular image is​ missing.​

​2.​ ​Include Primary Navigation Actions​
    ​●​ ​Play:​​Will eventually direct users to the simulation introduction or mode selection​ ​page.​
​   ●​ ​Learn About CAC:​​Direct users to information about​​CAC, its mission, services,​ and community impact.​
    ​●​ ​Donate:​​Direct users to CAC's official donation page.​

​3.​ ​Keep in mind Responsive Design and Accessibility​
​   ●​ ​Use semantic HTML and accessible navigation elements.​
​   ●​ ​Buttons and links are keyboard-accessible.​
   ​●​ ​Images include descriptive alternative text where appropriate.​
​   ●​ ​Implement appropriate hover, focus, and active states for interactive elements.​
​
# Dependencies​

    ●​​ Approved Landing Page UI Design (Figma) & image urls.​
    ​●​ ​Completed Frontend Global Setup (React and TypeScript).​
    ​●​ ​Confirmed CAC donation URL and informational content.​
